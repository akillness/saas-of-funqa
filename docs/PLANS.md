# Planning Process and Conventions

## Workflow
1. **Requirements Gathering**: Describe the feature in `docs/product-specs/`.
2. **Technical Design**: For significant changes, create a design doc in `docs/design-docs/`.
3. **Execution Plan**: Create a plan under `docs/plans/work/` with a 3-digit zero-padded prefix (e.g., `001-add-rag-api.md`).
4. **Execution**: Follow the execution plan, updating the Status from `Active` to `Completed` as tasks finish.

## Execution Plan Template
```markdown
# [Plan Name]

**Status:** Active | Completed

## Goals
- [ ] Item 1
- [ ] Item 2

## Steps
1. Task A
2. Task B
```
